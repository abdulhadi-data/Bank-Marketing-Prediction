# Data

This project uses the Bank Marketing dataset from the UCI Machine Learning Repository.

## Dataset

The dataset contains 45,211 records from a Portuguese bank's telemarketing campaigns and includes customer demographic, financial and campaign-related variables.

The target variable is:

- `y` - whether the customer subscribed to a term deposit (`yes` / `no`)

## Source

UCI Machine Learning Repository - Bank Marketing dataset

The raw dataset is not stored in this repository. To reproduce the analysis, download `bank-full.csv` from the original UCI source and place it inside this `data/` folder.

The analysis script expects the following path:

`data/bank-full.csv`
